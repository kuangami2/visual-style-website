# 《晚些回去》声音设计

## 采用的方案

安静进入，用户主动打开声音后，播放原创程序生成的风与叶片沙沙声。自然氛围是主层，音乐保留为未来可独立开关的辅助层。当前声音没有调用外部服务，也没有使用来源不明的音频。它是环境声合成，**不是田野实录**；页面里的“自然声”描述听感类别。

本作靠明艳的光、人物关系和停留感建立个性。持续旋律容易盖过这种留白，因此不把一首泛用“古风免费纯音乐”替换成默认背景。未来加入音乐时，优先低密度的古琴泛音或轻笛箫，避开强鼓点、主唱和完整主旋律，并让用户独立选择。

## 本次修正

旧版用单声道滤波噪声、缓慢周期调制和 12 秒循环，主增益为 0.022。这个数字单独不能表示响度，但叠加原波形本身的低幅度后，会造成部分电脑上几乎听不见。声音的持续低频、设备的频响和过于规则的变化，也可能让人觉得像电器或蜂鸣。没有用户设备录音，不能把其听感断言为某一个声学原因。

上一份说明把首尾各淡出至静音称为“交叉淡入淡出”，这是不准确的。首尾各自归零会形成循环中的安静凹口；短噪声循环也不必然产生有音高的蜂鸣，真正的周期性接缝、不连续点或窄带共振才需要分别排查。

现在的实现位于 `src/ambient.ts`：

- **48 秒立体声。** 中央的风声提供主体，两侧独立叶片噪声提供空间感。24 kHz 采样率足够覆盖设计频带。
- **真实的 4 秒等功率交叉淡化。** 将额外生成的尾部与开头重叠，权重分别为余弦和正弦；两端不轮流归零，循环边界对应原始连续噪声中的相邻采样。
- **不使用振荡器。** 宽频噪声经过柔和滤波，降低沉重低频；风势按随机间隔平滑变化，不用固定正弦节拍，也不模拟容易变成电子哨声的鸟叫。
- **可听见但克制的响度。** 合成波形做 RMS 和峰值约束，播放增益为 0.28。开启用 0.9 秒渐入，关闭用 0.45 秒渐出；快速切换会取消旧的暂停任务。
- **页面生命周期。** 切到其他标签页后渐出并暂停音频上下文，回到页面时恢复原有开启选择；关闭后不恢复。组件卸载释放音频节点和事件监听器。浏览器不支持或拒绝启用时返回关闭状态。

“分镜”的声音栏是后续影视制作建议，不表示网站已经播放了鸟鸣、溪水或衣料拟音。当前网页只播放风与叶片这一层环境声。

## 实际波形检查

对当前固定种子生成的整段立体声进行数值检查，结果如下。这里的 dBFS 是数字信号电平，不是用户耳边的声压，也不能代替在具体扬声器上的试听。

| 检查项 | 结果 |
| --- | --- |
| 时长 / 声道 | 48 秒 / 2 声道 |
| 播放后的平均 RMS 电平 | 左 -26.95 dBFS；右 -27.00 dBFS |
| 播放后的峰值 | 左 -13.43 dBFS；右 -13.94 dBFS，未削波 |
| 左右声道相关系数 | 0.487，保留主体与立体声差异 |
| 循环边界采样差 / 日常相邻采样差 RMS | 左 0.060 / 0.146；右 0.0035 / 0.144，没有额外的边界大跳变 |
| 80 Hz 以下能量占比 | 约 0.48%，避免低沉轰鸣主导 |
| 窄频尖峰检查 | Welch 频谱中，50 Hz 以上最强窄频采样点仅比邻近均值高约 1.37 dB；未见明显单频峰 |

频谱检查使用 16,384 点 Hann 窗、50% 重叠，共 139 窗。结果用于排查电平、接缝和稳定音调问题，不把“更自然”当成已由数值证明的结论。

## 未来加入纯音乐的条件

“免费收听”“免费下载”和“可用于公开网站”是不同权限。只选许可条款可验证、允许本项目公开使用的作品，并保存原始作品地址、作者、下载日期、许可证版本、署名方式以及编辑和循环许可。可考虑明确的 CC0，或按要求署名的 CC BY；不能仅凭平台的“免费”标签加入素材。

音乐加入后应单独开关、默认关闭，曲目署名在页面可见；实际电平应按听感与短期响度检查调低，使其不掩盖风与叶片。当前版本不因寻找音乐而增加第三方下载、隐性外链或额外等待。

## 人工验收建议

- 首次进入无声；从互动页和结束页都能打开、关闭，快速连点不叠加多层声音。
- 在耳机和笔记本扬声器上，以日常系统音量试听至少一整轮，确认舒适度；音频波形检查不能替代此项。
- 切走标签页后声音停下，返回时按原选择恢复；关闭状态下切回来仍保持安静。
- 小音量仍能听到轻风和细碎叶声，没有持续哨声、循环爆音或每隔十几秒一次的全静音。
