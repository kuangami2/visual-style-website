# 《晚些回去》项目调研与设计结论

## 方向

作品采用可随时停留的短篇互动绘卷（原设计目标为 5–8 分钟，实际时长由用户决定）：玩家是同行者，沿着“遇花 → 编环 → 分梅 → 等夕阳”四章前进。每章只有一个轻动作，没有失败惩罚，把注意力放在三位朋友之间的关系和环境变化上。完成后生成横屏、竖屏两版六镜头分镜包。

## 可借鉴的案例

- [Sky: Children of the Light](https://www.thatskygame.com/)：用探索和共同经历建立情绪。项目借鉴“场景变化 + 同行动作”的节奏，不引入联网社交和养成系统。
- [数字敦煌资源库](https://www.e-dunhuang.com/index.htm) 与 [数字藏经洞](https://cave17.e-dunhuang.com/)：把花枝、花环、青梅变成可发现的物件，让点击动作留下记忆线索，不复制其资料检索功能。
- [故宫青少版](https://young.dpm.org.cn/category/113)：故事场景配一个简单小游戏。项目把它收敛为采花、编环、递梅和选择同行者四个动作。

## 视觉系统

暖金侧逆光与青蓝阴影构成主调。三位友人穿象牙白透光外衫，内层分别为阿棠的珊瑚、青禾的玉绿、闻溪的天青。手部、发丝和花叶保留高光，页面只对阅读区压暗。

交互花材用杏花胭脂粉、栀子月白、桔梗天青、金盏暖金、紫藤浅紫，五种 SVG 花形配合颜色和文字区分。分梅使用独立面部裁图，桌面头像 86px，手机 78–80px。手机采用独立生成的竖图；平板和较窄电脑使用上图下文，避免标题覆盖人物。

## 交互结论

“等夕阳”支持多选同行者，并增加“听一会儿风、交换花环、讲一件小事”三种收束方式。选择会写入 URL，因此结局链接在新窗口打开时仍能重建同行组合；分镜导出在浏览器内用 Canvas 和 JSZip 生成，不上传用户选择。

## 素材策略

参考图只用于提取构图、光色和人物关系；正式素材由项目生图脚本生成，避免保留参考图的字幕、水印和黑边。生图密钥只在本地 `.env` 使用，前端不提供生图按钮，也不把密钥部署到静态站点。
