# 发布前设计复盘

## 视觉问题与处理

第一版生成图的光线偏灰，网页蒙层又把亮部压暗，和参考图的明艳黄金时刻不一致。本轮把提示词从“柔和、低饱和、暖雾”改成可验收的摄影条件：低角度侧逆光、发丝和透光袖口金色边缘、暖金高光与青蓝阴影分离、前景花叶大散景、清晰面部和自然饱和的珊瑚/玉绿/天青衣色。四张横图与四张竖图均重新生成，网页使用 v5 WebP 压缩副本；六张分镜另有 v6 横竖构图，避免手机裁切掉同行者。

页面暗罩现在只在文字阅读区和底部提供对比度，人物区保留逆光细节。1024px 左右的窄桌面使用上图下文布局；手机使用独立竖图，并将交互内容放到图片下方。三位朋友在“分梅”与“等夕阳”使用独立头像裁图，头像尺寸在桌面和手机均保持可辨识。

## 交互复盘

- 采花严格限制三朵，已选花可再次点击撤回；五种颜色和五种 SVG 花形同时区分。
- 花环显示所选花材的颜色、形状和名称；四个位置完成后主动继续。
- 分梅先显示角色回应，再由用户点击继续，避免自动跳章和误触。
- 等夕阳支持一、二、三位同行者、全选快捷操作，以及听风、交换花环、讲小事三种收束活动。
- URL 只接受白名单同行者、活动、花材和赠梅对象；刷新可恢复，重新游历会清空。
- 结尾页仍可控制自然声、分享选择和导出分镜；旧导出任务不会覆盖新的选择。

## 导出复盘

导出 ZIP 包含横屏 1920×1080 与竖屏 1080×1920 各六张 JPG、`storyboard.json`、带 UTF-8 BOM 的 CSV、SRT 和说明文件。JSON 同时提供 `sourceImage`、`horizontalFile` 与 `verticalFile`，路径都能在 ZIP 内解析；CSV 也列出两版文件名。竖版使用独立手机主图，不再从横图强裁。

## 声音复盘

默认静音，用户主动打开原创程序合成的宽带风叶声。声音引擎不使用固定振荡器或来源不明音频；48 秒立体声片段用等功率交叉淡化循环，支持标签页隐藏暂停、返回恢复和结束页关闭。纯音乐只在未来取得可核验公开授权后作为独立可选层加入。

## 验收范围

最终自动化验收记录在本机 `tmp/final-qa.json`，未进入部署包：1440、1024、390、320 宽度；四章完整流程；一至三位同行者和三种活动；分享恢复；声音快速切换；实际 ZIP 解包、12 张图片尺寸、JSON/CSV/SRT 路径和时间轴；零 JavaScript 异常和资源请求失败。仓库内 `npm run test:e2e` 负责持续 smoke 检查，`npm run assets:check -- --strict` 负责发布素材完整性。

## 已知边界

图片模型每次独立生成仍可能产生细微面部差异；提示词和固定服饰已尽量保持角色一致。声音数值检查不能替代不同耳机和扬声器上的人工试听。GitHub Pages 是静态站点，生图脚本只在本地运行，网页不会暴露 API key。未完成旅程只保存在当前标签页；清理旧派生图不会删除 `assets/generated/` 中的源图。
